## Responsibilities

The maintainer is responsible for:

- Reviewing and merging pull requests
- Triaging issues and security reports
- Managing releases and versioning
- Maintaining CI/CD pipelines
- Enforcing the Code of Conduct
- Setting project direction and roadmap

## Becoming a Maintainer

As the project grows, additional maintainers may be invited based on:

- Sustained, high-quality contributions
- Deep understanding of the codebase and architecture
- Alignment with the project's mission and values
- Availability for regular review and triage work

Interested contributors should express interest via GitHub Discussions.
